# Сайт жилищного комитета

Сайт жилищного комитета администрации г. Северогорска (организация условная).
Сделан в рамках производственной (эксплуатационной) практики.

Студент: Нева Александра Александровна, направление 38.03.05 «Бизнес-информатика».

## Исходные данные

- Репозиторий: https://github.com/yilmazerseyma660/zhilkom


### Учётные записи

| Роль | Логин | Пароль | Что может |
|------|-------|--------|-----------|
| Администратор | admin | admin123 | всё, что сотрудник + назначает роли и блокирует пользователей |
| Сотрудник комитета | sotrudnik | sotr123 | отвечает на обращения, добавляет/правит/удаляет новости и статьи, создаёт учётные записи жителей |
| Житель | zhitel | zhitel123 | отправляет обращения и ведёт по ним переписку, редактирует свой профиль |
| Житель | orlova | orlova123 | то же, что и житель |

Создать пользователя можно двумя способами:
1. Сам пользователь — через страницу «Регистрация» (получает роль «Житель»).
2. Сотрудник — в «Панель управления → Пользователи → Добавить пользователя»
   (сотрудник создаёт только жителей, администратор — с любой ролью).

## Технологии

- Python 3.11, Flask, Flask-SQLAlchemy
- БД: SQLite (по умолчанию) или MySQL из XAMPP
- HTML, CSS, JavaScript (без CMS и без готовых CSS-фреймворков)

## Страницы сайта

1. Главная — баннеры (слайдер), лента новостей, разделы, новые материалы
2. О комитете — задачи, руководство, структура, график приёма
3. Новости — лента с постраничным выводом и страница новости
4. Материалы — три раздела по 5 статей («Жилищные программы», «Капитальный ремонт», «Жильцам многоквартирных домов»)
5. Контакты — адрес, телефоны, форма обратной связи
6. Поиск по сайту
7. Вход / регистрация
8. Личный кабинет — обращения (переписка с комитетом) и профиль
9. Панель управления — обращения, сообщения с формы, пользователи, новости и статьи

Дополнительно: карта сайта (`/sitemap`), страница 404 (на неё перенаправляет любой несуществующий адрес),
версия для слабовидящих по ГОСТ Р 52872-2012 (размер шрифта, три цветовые схемы,
отключение картинок, межбуквенный интервал).

## Запуск на своём компьютере

```
pip install -r requirements.txt
python app.py
```

Сайт откроется на http://127.0.0.1:5000. База `zhilkom.db` создаётся и заполняется сама при первом запуске.

### Запуск с MySQL из XAMPP

1. Запустить в XAMPP Apache и MySQL.
2. В phpMyAdmin создать базу `zhilkom` (кодировка utf8mb4_general_ci).
3. Перед запуском задать переменную:

```
set DATABASE_URL=mysql+pymysql://root:@localhost/zhilkom
python app.py
```

## Размещение на Render

1. New → Web Service → подключить репозиторий с GitHub.
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `gunicorn app:app --workers 1`
4. Тариф Free.

Или через Blueprint — в репозитории лежит `render.yaml`.

На бесплатном тарифе диск не сохраняется между перезапусками, поэтому после
перезапуска база создаётся заново с начальными данными.
